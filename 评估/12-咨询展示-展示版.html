DevAgent · 进展与路线图

口述按三个关键点展开；下方「关键数据快照」用于背书。口径与 评估/12-咨询展示-进展与路线图.md 一致。

三个关键点

关键点一 · 检索侧闭环

软熔断（Dense 距离分桶 + 阈值）把「过检索」量化；端到端 + bad case 驱动 Prompt / 工具描述 迭代。首轮第一层 FP 高 → Prompt v2 后 一致率 63.3%→97.8%，FP 33→2。

LLM-as-Judge 作为第三层系统评测：分层 rubric（bucket + grounding_tier），回答质量与「调不调工具」解耦。

关键点二 · 大仓库迁移 + 数据飞轮 + SFT

大仓库迁移（三层）：① 评测语境——对齐真实大代码库尺度（检索更噪 → 软熔断 / 分档 / E2E 分桶）；② 工程基准——experiments/external/ 用 pin 过的 Transformers + FastAPI 克隆做大仓 RAG 基准，与主仓日常 src/ 索引隔离；③ 数据飞轮——私域/远域/误导切片模拟大仓里的研发任务，与①同一条故事线。

飞轮：多样化 + 配比；机器过滤 + 人工抽样 → ShareGPT → 训练。首轮 SFT：路由 + JSON + 决策（Phase 2A）。后续：检索后生成、DPO 等另划界。

关键点三 · 前沿思路（计划）

借鉴 RAGAS 的启发式方法，评估召回后的回答质量（与现有 E2E + Judge 互补）。

借鉴 Self-RAG 思路做后训练，提升工具调用链上的反应与决策质量（与 Phase 2A 路由 SFT 衔接）。
